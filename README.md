# Original Skinn – Shopify theme

The Original Skinn website as a Shopify theme, ported from the approved test site
(original-skinn.vercel.app). Built step by step:

1. Development store set up
2. Theme foundations – page frame, fonts and colours, announcement bar, header, slide-out menu, footer  ← this step
3. Products and collections
4. Home page sections
5. Collection pages
6. Product page
7. Bag and free-delivery bar
8. Information pages
9. Ritual bundles and reviews
10. Testing and handover to the live store

Pages that aren't built yet show a temporary "being built" message.
